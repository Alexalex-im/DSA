Binary Search Tree vs AVL Tree

---------------------------------------------------------------------------------
|                              |           BST        |             AVL         |
---------------------------------------------------------------------------------
| Create Tree                  |       O(1)           |         O(1)            |
---------------------------------------------------------------------------------
| Insert a node Tree           |       O(n)           |         O(Logn)         |
---------------------------------------------------------------------------------
| Traverse Tree                |       O(n)           |         O(n)            |
---------------------------------------------------------------------------------
| Search for a node Tree       |       O(n)           |         O(Logn)         |
---------------------------------------------------------------------------------
| Delete node from Tree        |       O(n)           |         O(Logn)         |
---------------------------------------------------------------------------------
| Delete Entire Tree           |       O(1)           |         O(1)            |
---------------------------------------------------------------------------------
