Recursive vs Iterative Solution 


Recursive 

static int powerOfTwo(int n) {
    if (n==0) {
        return 1;
    } else {
        var power = 2 * powerOfTwo(n-1);
        return power;
    }
}

Iterative 
static int powerOfTwoIT(int n) {
    var i=0;
    var power = 1;
    while (i < n) {
        power = power * 2;
        i = i + 1;
    }
    return power;
}


points                  Recursive       Iteration

Space efficient?         No               Yes           No stack memory require in case of  iteratiom

Time efficient?          No               Yes           In case of recursion system needs more time for pop and push elements to stack memory which makes recursion less time efficient

Easy to code?            Yes              No            We use recursion especially in the cases we know that a problem can be divide into similar sub problems.
