Hash Functions

    Mod function 

    int mod(int number, int cellNumber) {
        return number % cellNumber;
    }

    // mod(400, 24) --------> 16
    // mod(700, 24) --------> 4

    0  1  ...  4   5  ...  16  ...  23
              700     ... 400  ...
